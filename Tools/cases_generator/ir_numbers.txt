# Pinned handler numbers of the register IR (Tools/cases_generator/ir_numbers.txt).
#
# A number is a fact of the .pyc format: change it only with a bump of the
# magic number (Include/internal/pycore_magic_number.h), which the integrator
# makes at the landing.  Lines are `NAME NUMBER`, sorted by number within a
# section.  The generator reads this file in place of numbering the sorted names.
#
# To add a handler, give it a line in its region and the next free number.
# To remove one, rewrite its line as `# removed: NAME NUMBER`; the number is
# not reused within a format revision, and the slot is a hole (a zeroed
# _PyIR_Formats row, an
# UNKNOWN_OPCODE dispatch entry).  `ir_numbers.py --check-numbers` (run by
# `make regen-cases`) proves that this file matches Python/bytecodes.c.

# Constants: the class bounds.  Real opcodes up to HAVE_ARGUMENT take no
# argument (HAVE_ARGUMENT counts CACHE, so it is itself the last of them);
# those from MIN_INSTRUMENTED_OPCODE are instrumented.  Handlers of
# the IR only start at IR_FIRST_ONLY_HANDLER, after the pseudo-instructions.
