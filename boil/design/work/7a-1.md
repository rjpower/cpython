## Invariants the rung relies on

- A heap block's segment's sub-process is that of the interpreter whose
  thread allocated the block, until absorption moves it to the main
  interpreter's (note 13 section 2).
- The domain has one GIL (commit 6; until it lands, the all-true
  `InterpreterConfigTests` row is the only creator of the other case,
  and it runs on one OS thread).
- No Python code runs between a collection's batch and its splice.
- Every mark holds the head lock from `live_domain()` to the end of the
  heap walk, and the adoption takes it, so a mark sees an interpreter
  either in the domain or adopted.
- `_PyGC_LiveVisitRoots()` runs for every domain interpreter, so every
  queue and every adopted state is a root of every domain collection.

## Risks

- **A test that waited for another interpreter's callback on the
  collecting thread.** Commit 3's set runs every interpreter and
  threading suite; a failure is traced (PROCESS.md section 4) and is
  either a test that assumed the old rule (adjusted, with the reason in
  its commit) or a missed drain point.
- **Draining with collection off.** Commit 2 makes `_Py_RunGC()` drain
  under `gc.disable()`; a test that disables gc to keep finalizers from
  running between two statements now sees a queued call run at the next
  breaker. That is when it ran before an inline collection left it
  queued; traced if a test shows it.
- **Absorption.** `_mi_subproc_absorb()` edits mimalloc's abandoned
  bookkeeping. Its preconditions (no thread of the retired
  sub-process, the GIL held, the head lock held, main's locks first)
  are asserted in debug builds; 9.7 (e) exercises it a hundred times
  under ASan.
- **Heap immortals of adopted states** live as long as the process (the
  `all` and `any` of every deleted legacy interpreter and what they
  reach): recorded in 9.7 (e)'s RSS.
- **The close's metadata walk** costs a heap walk of the closing
  interpreter's sub-process per shared-heap teardown; recorded in
  `test_capi.test_misc`'s time and in 9.7 (e).
- **`take_gil()` cost.** One relaxed load and a branch per acquisition;
  measured by the pipe-read loop.
- **Concurrent rungs.** 10a edits gc_trace.c's verifier,
  pycore_gc_trace.h, _testinternalcapi.c and test_gc.py. The hunks here
  are disjoint; each merge of the integration head is checked with
  `git diff` over those files before the next commit.
