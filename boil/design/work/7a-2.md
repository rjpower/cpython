## What changes, by commit

Gate 1 per commit on build/default and build/debug; the C mode on every
precise function edited.

1. **Order across owners** (gc_live.c). The order table allocated before
   the first node whenever the dead set holds call-bearing objects of
   more than one owner, bounded by the dead count (stamps and the
   traversal stack), its failure on collect()'s one path with no batch;
   `order_calls()` between `queue_destroy_hooks()` and `route_calls()`;
   the waiting list per owner (a root); release on the last
   predecessor's completion; `gc_queue_info()["waiting"]` (3.5). Gate 1:
   test_gc (9.10, 9.14, `test_finalizer_order`,
   `test_dealloc_reads_referents`), test_io, test_finalization.
2. **Destruction metadata by owner** (gc_trace.c, codeobject.c,
   pycore_code.h, dictobject.c, typeobject.c, the docs). Per-entry
   watcher masks; the owner passed to `live_destroy_hook_of()`;
   `_PyCode_HasExtraFree(interp, op)`; the refusal in `PyDict_Watch()`,
   `PyType_Watch()`, `PyUnstable_Code_SetExtra()` (3.4, PROCESS.md 0.2).
   Gate 1: test_gc (9.9 a, b's first half, c), test_capi.test_watchers,
   test_code, test_capi.test_misc.
3. **The close's retirement and publish, adoption and absorption**
   (gc_live.c, gc_trace.c, pystate.c, arena-abandon.c, mimalloc
   internal.h, codeobject.c, _testinternalcapi.c). The close's four steps
   (5.1); `retire_metadata()`: the freeze, the watcher-bit walk, the
   restart loop with `_PyCode_ClearExtras(co, 1)` and
   `gc_queue_info()["retired"]` (5.2); `_PyGC_LiveAdopt()`; adopted
   states as roots; roots relinked; `_mi_subproc_absorb()` with 5.3's
   lock order and `gc_queue_info()["absorbed"]`; the main interpreter's
   deletion freeing adopted states; an isolated interpreter's state
   freed (5.4). Gate 1: test_gc (9.5 c, 9.7, 9.9 b and d, 9.18) under
   `PYTHON_GCVERIFY=kill` on debug and on build/asan,
   test_capi.test_misc, test_embed, test__interpreters.
4. **The fork child** (pystate.c, gc_live.c, pycore_gc.h).
   `dispose_after_fork()` (5.5). Gate 1: test_gc (9.13), test_os,

## Risks

- **A main-interpreter call waiting on an idle subinterpreter** (3.5): a
  test expecting it at once is traced; the dependency is real.
- **Absorption** edits mimalloc's abandoned bookkeeping: preconditions
  asserted in debug builds; 9.7 (e) a hundred times and 9.18 under ASan.
- **Retirement cost**, O(heap × extras): measured with the dynamo-shaped
  case; a bad number is a later rung's single form.
- **The registration refusal** breaks an extension that tags another
  interpreter's object on a shared heap; none is known in the tree.
- **Concurrent rungs**: codeobject.c and pycore_gc_trace.h with 10a;
  dictobject.c and typeobject.c with 6d and 10a.
