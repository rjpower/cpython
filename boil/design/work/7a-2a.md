# 7a rung 2a: sweep safety and dependent finalizer completion

Status: prepared 2026-10-29; design review and implementation pending.
Starts only after the queue rung-1 and compiler-fix landings. The detailed
handoff inventory is `7a-2.md` commits 0 and 1; note 13 section 3.5 gives
the corrected invariant. No rung-2 code has been implemented.

Own `Python/gc_live.c`, its explicit test-hook declarations and fixtures,
and the corresponding tests in `Lib/test/test_gc.py`. Coordinate shared
header/module additions with the roots lane. This split does not change
owner metadata, heap adoption or interpreter deletion.

1. Compute referrer-first sweep order before freeing anything. A failed
   ordering allocation undoes dead flags and frees nothing; an injected
   failure must preserve a flagged referent chain until a later successful
   ordered collection. No heap-order fallback is permitted.
2. Probe S3 and buffer Python debug output until no dead snapshot is held.
   Test a Python stderr writer that releases the GIL while another domain
   member collects, with kill and ASan.
3. Extend the reproduced S1 probe to BufferedWriter/FileIO and multiple
   unfinished predecessors. Enforce completion dependencies for same-owner
   and cross-owner calls while allowing unrelated calls to proceed.

Before code, review the dependency construction, checked storage bound,
root traversal and per-completion release accounting. The old owner-count
allocation condition and per-owner last-call shortcut are withdrawn:
several earlier calls of one owner may remain unfinished. Allocation
failure occurs before batching and follows the one rollback path.

Smallest gates: failed-order fixture, S1/S3 resource probes, existing
finalizer/referent-order tests; then test_gc, test_io, test_pyexpat,
test_xml_etree, test_threading and test_finalization on default/debug,
with active child kill assertions. End gates include the collector
verification set, ASan hazards and required unbuilt-module checks.
Record controls by source patch, build and mode. Refresh instruction,
allocation/box, RSS and queue-latency evidence at this split's boundary.

Acceptance: no sweep after ordering failure, no Python over a dead set,
and no dependent resource finalization before all predecessor calls
complete. Record the actual graph complexity rather than inheriting the
old O(K*D) claim. Coordinator arranges review and landing before 2b.
