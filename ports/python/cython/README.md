# Cython

A build tool: ports that generate C with Cython name it in `build_ports`, so
their extensions are generated by this patched copy. It builds as pure
Python (`NO_CYTHON_COMPILE`), since only code generation runs it.

`code-cache-roots.patch`: under `Py_GC`, the code object cache keeps its
code objects in a dict that is a collector root (`PyGC_AddRoot`), since the
cache's entries live in `PyMem_Malloc` memory that no `tp_traverse` visits.
