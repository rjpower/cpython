# `_struct` value packing

`Struct.pack`, `pack_into` and the module functions receive a borrowed, contiguous `PyValue` argument window. Packing must retain that window and the destination buffer throughout each conversion and callback. Format arguments are consumed in order; do not pre-convert, change alignment or repeat behavior, or move the existing buffer cleanup. `pack_into` can leave partial writes on failure, so error-path writes are observable.

The proposed [packing continuation](../issues/checkpoint-closure/struct-pack-value-proposal.md) gives the private `formatdef.pack` callback a borrowed value. Its native, big-endian and little-endian tables and endian-table substitutions must all use that same signature. Unpacking is a separate path.

Integer codes duplicate an integer value or call value-aware `__index__`, then hold that owner until the signed, unsigned, size or pointer extractor finishes. Preserve `struct.error` conversion and range diagnostics. Endian 64-bit packers use the [value byte-array provider](../issues/checkpoint-closure/long-value-bytearray-provider.diff), a thin wrapper over the existing span encoder. It preserves partial writes on overflow and the existing signed/unsigned and exception contract; a checked scalar conversion followed by a write is not equivalent on failure.

Float and boolean codes use value-aware double and truth conversion while preserving callback order and exception mapping. Complex codes pass pointer-space inputs to the existing complex converter, including its `__complex__` and `__float__` rules; an inline integer or float becomes a real component with positive-zero imaginary component. Byte, string and Pascal codes check for concrete bytes or bytearray before borrowing their pointer; invalid inline inputs take the same format-specific error path. None of these paths projects a primitive solely to satisfy an old object-form packer.

The W5 [implementation](../issues/checkpoint-closure/struct-value-pack.diff) and [regression](../issues/checkpoint-closure/struct-value-pack-tests.diff) are queued for review and integration. The worker release build passed `test_struct` and focused differential probes against the verified upstream extension, including native and non-native overflow writes. This is not merged qualification. A real 32-bit build, opposite-endian host, debug checks, complete runtime box gates and performance comparison remain to be run at integration.
