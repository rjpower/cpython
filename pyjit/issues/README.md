# Experiment records

The [current interpreter plan](interpreter-round51/plan.md) belongs to the
[baseline stage](../stages/02-baseline/README.md). See [status](../STATUS.md)
for project qualification and the [stage map](../ROADMAP.md) for dependencies.

Experiment directories hold bounded proposals, independent reviews, test and
measurement evidence, and decisions. Their presence does not by itself establish
that work is active or admitted. New experiments use the
[template](_template/status.md), identify a parent workstream and retain the
evidence needed to assess the change. The coordinator validates composition.
