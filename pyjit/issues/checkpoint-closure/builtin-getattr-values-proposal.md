# Value-native builtin getattr proposal

Scope: `Python/bltinmodule.c`, based on runtime `af82c03c4e5`. Replace the current `METH_FASTCALL` object-window `builtin_getattr` with a `METH_VALUE` positional-window function and update its single method-table entry. The ordinary value-call trampoline rejects keywords using the existing builtin diagnostic; unlike fixed `METH_O`, it does not enforce a 2–3 argument range, so the body must retain `_PyArg_CheckPositional("getattr", nargs, 2, 3)` before inspecting arguments.

Borrow receiver, name and any default from the stable call window throughout lookup. Attribute providers require an object name. If the name is inline, it cannot be Unicode: raise `TypeError` with the same `"attribute name must be string, not '%.200s'"` message and `PyValue_TYPE(name)->tp_name` used by `check_attribute_name` in `Objects/object.c`, with no object projection. Otherwise pass `PyValue_AsKnownObjectBorrow(name)` to the existing provider and let it validate Unicode and subclasses; this preserves its exact error and custom name behavior. Do not call user callbacks before name validation.

Without a default, return the owned `_PyValue_GetAttr(receiver, name_object)` result directly. With a default, `_PyValue_GetOptionalAttr` returns status 1 with an owned result, status 0 with no error, or -1 with an error: return the result on 1, `PyValue_DUP` of the borrowed default on 0, and `PyValue_NULL` on -1. This preserves AttributeError-only suppression and the current descriptor and `__getattribute__` ordering while avoiding boxes for receiver, result and inline default. The borrowed window and name remain live across any lookup callbacks. The function remains positional-only and has the same docstring.

Focused validation: W5 shadow build/import plus selected `test_builtin` getattr cases; direct differential probes for argument count and keywords, inline and heap invalid names, Unicode subclasses, inline receiver/results/defaults, custom descriptor and `__getattribute__` raising AttributeError and other exceptions, and reentrant callbacks. Verify the malformed-name diagnostic exactly matches upstream. Root handles the full suite and a fresh raw box capture.
