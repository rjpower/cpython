# Decimal formatting and current-context lifetime review, round 1

`decimal-format.diff` preserves the value result from the cached `_pydecimal.Decimal` constructor through `__format__`, and closes the method, arguments, and constructed Decimal on all visible result paths. The override-dictionary reader holds its value while encoding it. The generated `METH_VALUE` wrapper preserves the positional and type checks.

**Blocking lifetime finding:** `optional_context_value(state, None)` returns a borrowed current Context. In the contextvars build, `CURRENT_CONTEXT` immediately decrefs the new reference returned by `current_context()`. `Decimal.__format__` then passes that borrow through warning dispatch and, for unsupported format specifications, arbitrary `_pydecimal.Decimal` construction and `__format__` callbacks. A callback can replace the current Context, leaving the old borrow dangling before the fallback duplicates it or the formatter uses it. Take a new reference immediately after the lookup, before any callback, and release it on every early return, fallback, and normal finish.

The same confirmed pattern affects two queued value paths. `localcontext()` retains the borrowed `global` until after `context_setattrs_value`, whose numeric conversion can invoke a user `__index__`; transfer an owned `global` into the manager and close it on errors. `dec_richcompare_value` retains a borrowed Context through Rational ABC checks and numerator/denominator getters, then calls `dec_addstatus` with it; own the Context before conversion and release it on each result path. Other inspected `convert_op_value` paths accept exact Decimal or raw integer spans, and explicit Context arguments remain held by Clinic arguments or the Decimal receiver; those do not justify a blanket refcount rewrite.

The focused formatting tests previously reported by the author check behavior but do not prove the current-Context replacement case. Add one reentrant test per confirmed path, then rerun the relevant formatting, localcontext, and Rational comparisons. This receipt reviews source only; a corrected additive patch needs a separate round-2 review.
