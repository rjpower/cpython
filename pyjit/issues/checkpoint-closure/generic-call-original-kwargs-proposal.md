# Generic callable: original keyword dictionary ordering

For `_PyValue_Call` with nonempty keyword dictionaries, return `_PyValue_NotCallable` immediately for an inline callable before unpacking keyword names. Inline values cannot be callable in the current dispatcher. This restores the not-callable error without projection or changing vectorcall validation.

For an object callable, retain the existing ordinary object-slot path first. Before unpacking keywords, select a narrow internal typeobject helper only if dispatch would reach the exact pair `tp_call == slot_tp_call` and `tp_value.call == slot_tp_call_value`, and neither the actual instance value-vectorcall nor object-vectorcall field is active. Check both actual fields under the same `Py_TPFLAGS_HAVE_VECTORCALL` and offset rules as `_PyValue_VectorcallTstate`; a custom active vectorcall always keeps its existing path. Require a non-Unicode dict key for this rare path, using borrowed dictionary words without callbacks; ordinary calls remain unchanged. The tuple and original dictionary remain owned by the caller for the complete operation.

Under the same recursion guard as selected type-slot dispatch, invoke the exact object `slot_tp_call(self, args, kwargs)` and convert its checked result to an owned PyValue. This invokes existing `call_method` lookup and descriptor binding before the callee validates keyword names, preserving upstream callback/error order. It is a temporary core object-result bridge, not an external boundary: a value-native tuple/dict special-method continuation can eliminate any resulting primitive projection later. Preserve null/error checks and release recursion guard on all paths. Keep the AST/type-call-specific continuation separate and preserve global vectorcall string-key validation.

Verify the original direct C `PyObject_Call` descriptor-order repro against upstream and candidate; include raising descriptors, callable descriptors, mixed/non-string keys and error text, inline int/float not-callable, normal string kwargs and active vectorcall cases. Only the selected generic pair should take this path. Minimal focused compile and call/descriptor tests precede integration; no full suite in this packet.
