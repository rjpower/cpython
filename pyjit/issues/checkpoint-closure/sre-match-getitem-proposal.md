# SRE match value subscript proposal

Scope: `Modules/_sre/sre.c`, against runtime `af82c03c4e5`. The current match type installs only the object `Py_mp_subscript`; the adapter therefore boxes each inline group key before calling `match_getitem`. The profile attributes 577,450 boxes to that site, but this proposal does not claim all are eliminated without a new capture.

`match_getindex` already accepts a borrowed value and is shared by `group`, `groups`-related paths, `start`, `end`, and `span`. Keep its default/null branch, `__index__` test and `_PyValue_AsSsize_t(index, NULL)` exactly as they are, including errors from custom index implementations and conversion overflow. For the other branch, pass the existing borrowed `index` directly to `PyDict_GetValue` for `pattern->groupindex`; retain its owned result through the existing long/subclass check and conversion, then close it. This removes the object projection while retaining hashing/equality callbacks, dictionary lookup error propagation, the `no such group` fallback, and branch ordering. The caller holds the borrowed key across lookup and callbacks.

Add `match_getitem_value(PyObject *op, PyValueBorrow key)`: call the existing `match_getslice` with the borrowed key and `Py_None`, and transfer its owned object result using `_PyValue_FromObjectResult`. That result is a string, bytes, None or error; no primitive numeric result needs projection. Keep the existing slice/buffer and default logic untouched for all current consumers. Replace the old object slot body with `_Py_VALUE_THUNK_SUBSCRIPT(match_getitem, match_getitem_value)`, and pair `Py_mp_subscript` with `{_Py_value_subscript, match_getitem_value}` in the immutable `match_spec`; include `pycore_slots.h` for the private slot identifier. The object thunk remains the real object-slot entry and the core value slot calls the value body directly. Match is immutable and non-instantiable, so this introduces no inherited mutable slot behavior.

Validate with a locked W5 shadow compile/import and focused `test_re` match/group cases plus direct differential probes: numeric, bool and named indices, negative/out-of-range and huge values, integer subclasses and custom `__index__` (including exceptions), invalid float and unhashable keys, named-key hash/equality callbacks, unmatched optional groups and bytes/string results. Exercise direct subscription and `group`/`start`/`end`/`span` since the group lookup is shared. Compare exception classes and text with the upstream reference. No full suite or raw benchmark is part of this packet.
