## Entry and descriptor dispatch

The caller's borrowed receiver/value enter as values; duplicate an owned value with `PyValue_XDUP` immediately and hold it until the existing cleanup point, preserving the old `Py_XINCREF(value)` across allocation, callbacks and mutation. Keep the strong type and name owners, immutable/type-name checks, Unicode-subclass copying, interning, type-cache invalidation and dictionary publication in their current order. Do not change mutable metaclass override dispatch: the existing value-slot pairing/inheritance machinery must fall back to the actual overriding slot whenever the type's object slot differs.

Replace `_PyType_LookupRef(metatype, name)` with `_PyType_LookupValue`; keep its owned result through descriptor dispatch and close at the old descriptor cleanup point. Its current status is 0 for both missing and an error, so check `PyErr_Occurred()` if its value is null, as the old `LookupRef` branch does. Inspect `PyValue_TYPE(descr)->tp_descr_set` only for a found value; inline exact numbers have no setter and need no projection. For a real setter, the descriptor itself is object space; call `_PyValue_DescrSet(descr_object, PyValue_FromObjectBorrow(self_object), held_value)`, preserving the true descriptor slot/adapter dispatch and deletion sentinel. The descriptor and the held type/name/value owners remain live until the callback returns. Core descriptors with value slots get values; genuinely object-form external descriptor setters remain explicit adapter boundaries.

For the existing exact interned Unicode name, use `PyDict_GetValue` to fetch the old owned value. Preserve its found/error and missing-deletion AttributeError/context behavior. Assert the same lock and exact dict/name invariants; retain dictionary watcher and hash/error semantics. This avoids introducing a nested dictionary critical section at an already-locked call site.
