# Constructor and numeric formatting box attribution

This receipt uses the frozen stats executable at `build/pyvalue-rc-repr-stats/python`, ELF build ID `cde3a2b6fca5f331552809346f473290617b3ca5`, and `build/pyjit-link-wave1/checkpoint-closure/typecall-format-values-stats-v2/receipt.json`. Counts are hot-loop deltas for 100 calls after a calibration dump. They describe that executable, not a subsequent source tree.

| Probe | Hot boxes | Proven cause | Bounded continuation |
| --- | ---: | --- | --- |
| class `__init__` returns an inline scalar | 98 | `Python/bytecodes.c:EXIT_INIT_CHECK` projects `should_be_none` only to fetch its type name. GDB on the frozen executable observed `_PyValueTemps_Box` called from generated `_TAIL_CALL_EXIT_INIT_CHECK` after the calibration dump. | Use `PyValue_TYPE(should_be_none)->tp_name` in the bytecode producer, then regenerate cases. Patch: `r27-bad-init-return-value-type.patch`. |
| inline noncallable `__init__` | 1 | `Python/specialize.c` asks `_PyType_LookupRefAndVersion` for an object; that function boxes its owned inline lookup result at `Objects/typeobject.c:6982` before `PyFunction_Check` rejects it. | Read with `_PyType_LookupValueAndVersion`; reject absent, inline and nonfunction values; transfer only a proven Python function as an object. Preserve version-tag and specialization-failure behavior. |
| `format(float, spec)` and float f-string | 100 each | `_PyValue_DescrGet` takes its object-slot adapter at `Objects/object.c:1867`, boxing the receiver before `Objects/descrobject.c:method_get`. | Pair `PyMethodDescr_Type.tp_descr_get` with a value getter. Use existing `descr_check_value` and `_PyCFunction_NewValue`, whose `m_self` stores `PyValue_XDUP`. Keep the object getter as a genuine descriptor-entry thunk and preserve `METH_METHOD` type validation. |
| `format(int, spec)` and int f-string | 100 parser boxes each, plus the descriptor boxes | `Objects/longobject.c:int___format___impl` directly calls `_PyValue_AsObjectAt(self, BOX_SITE_PARSER)` before `_PyLong_FormatAdvancedWriter`. | Add a value-aware advanced-integer writer that consumes the inline/span form while preserving all format-spec, error and subclass behavior. The direct `float.__format__` probe has no hot boxes because it bypasses method-descriptor binding. The generic float formatter should be fixed at the descriptor producer, not by relabeling the adapter as a boundary. The one-line `EXIT_INIT_CHECK` patch passed `git apply --check` against the frozen runtime source; no runtime source was changed or rebuilt for this attribution.
