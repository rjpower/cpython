# Cold binary constant folding: value continuation

The fresh warmup PC sample after the unary fold shows boxes in `get_const_value`, `eval_const_binop`, `const_folding_safe_multiply/power/lshift`, and `_PyCompile_ConstCacheMergeOne`. These form one vertical object-result path. Port only `fold_const_binop`: read both operands with the already-reviewed owned `get_const_value_value`, evaluate to an owned `PyValue`, then use `instr_make_load_const_value` so the cache and const list retain the result without an intermediate box. Preserve the existing no-fold behavior: a failed arithmetic operation other than `KeyboardInterrupt` clears its exception and leaves the original instructions; a failed operand read or instruction/cache write remains an error.

For direct arithmetic cases, call the existing `_PyValue_{Add,Subtract,TrueDivide,FloorDivide,Rshift,Or,Xor,And,GetItem}` operators with borrowed operands and return their owned result. The safe multiply, power, left-shift and remainder helpers need value signatures too. Read int magnitude, sign and bit count from `_PyLong_SpanOfValue` while each operand owner is held; use `PyValue_LongCheck` so inline ints, bools and int subclasses follow the same guards. For tuple/string/bytes repetition, inspect an object only under `PyValue_IsObject`, retain the same size/complexity limits and `_PyValue_AsLong` conversion; swap borrows recursively for the commuted case. Preserve the old branch order and limit arithmetic exactly. Then call the existing value operator. No helper creates an object from an inline operand merely to run a safety check.

This increment does not change `const_cache_insert`, key equality or `constant_from_key`: the previous unary packet already uses those functions through `_PyCompile_ConstCacheMergeValue`. Type-distinct `1`/`1.0`, signed-zero bits and recursive tuple/frozenset keys therefore keep their established cache semantics. A selected object key remains rooted by the const list after append. The old object helpers can be removed once their only caller is replaced; no object wrapper or hidden compatibility bridge should remain in this private compiler path.

Minimal verification: compile `Python/flowgraph.c`, run focused `test_compile` and `test_ast`, and probe folded arithmetic for small/large ints, bools, signed zero, tuple/string multiplication limits, huge power/shift refusal, division-by-zero suppression and duplicate constant reuse. Then rerun the same raw warmup stats probe. A residual cache-merge PC must be attributed to its actual caller before another port; this packet does not claim every compiler box is gone.
