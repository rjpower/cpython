## Residual cache caller audit

`_PyCompile_ConstCacheMergeOne` is also called for five assembler-owned byte buffers and three assembled tuples. Those inputs remain object values, so this packet must not replace those object homes. In `flowgraph.c`, `add_const` has three callers: the unary fold covered here, list/set folding of an object tuple or frozenset, and `TO_BOOL` folding of a bool object. Binary folding uses the same object `instr_make_load_const` path, and its evaluator still projects value-operation results to `PyObject *` for many arithmetic operations. A remaining cache-merge PC after this packet needs caller attribution before further edits: binary folding may have already boxed its result before calling the cache, whereas an assembler call should not produce an inline replacement. If the binary fold is responsible, carry both operands and the result through a value-specific evaluator and the existing `instr_make_load_const_value` continuation; keep object-only safety helpers for multiply, power, modulo and left shift until each has a reviewed value contract.
