## Complete body and current reads

`make_leaf_region` derives scalar indices from immutable final words. Its limits are 32 words, two attributes per path, one comparison and two terminal arms. The eight-home call window includes callable and NULL/self, so the current all-arguments-supplied admission caps declared arguments at six. It rejects cells/free variables, keyword-only/variadic/generator forms, exception tables and a nonplain entry. Validated constant homes are independently bounded, distinct and tagged CO_FAST_CONST. The optional allocation is initialized even on the no-feedback return path, included in size accounting, and freed with CodeExec; static execution records remain NULL. No serialized metadata or rooted object pointer is added.

The builder follows forward control flow and requires every original word to be visited once, with no loops, reconvergence or hidden suffix. Each accepted load's dependency bit must contribute to the predicate or selected result; an unused potentially raising read cannot disappear. Temporary definitions are tracked in order and consumed temporaries become unavailable. Roots are arguments, validated constants or live globals; calls, writes, arbitrary control flow and unknown operations decline. The corrected `leaf_format` pins exact roles, flags, effects, read/write/through extents and borrow masks for each admitted form. Generic read/compare/entry/return effects remain explicit guarded-runtime obligations. Small-int metadata's conservative allocation/raise flags have a separately audited in-range immediate-constructor obligation.

Runtime paths consult the selected function's globals/builtins and current executing handler/private typed feedback. Historical MONO/POLY/MEGA state is accepted only with a supported current handler and its newest private proof; `fb_begin`/`fb_record` preserve that meaning. No historical poly-table row executes. Global keys versions distinguish environments and retain the builtin absence proof. Attribute paths accept only supported shape/class handlers, with current type/shape or class/metaclass versions before dereferencing guarded values. Classmethod handler 111 is not treated as a scalar read. Existing-key rebinding observes the current home. Intermediate owner chains remain live because there is no callback, allocation, release, poll or mutation during the probes. Read only the selected result arm. The comparison computes the same mask operation as ordinary inline numeric comparison; only exact inline pairs enter the leaf predicate, while bool, mixed, heap numeric and custom cases fall back.

For comparison result `c` and false-sense bit `f`, `arm = 2 + (c XOR f)` selects path3 exactly when the original fused instruction takes its forward jump. Fallthrough is path2. Both predicate inputs are probed before choosing one result; no other result path executes.
