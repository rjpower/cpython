# Ordinary Python calls: ledger and structural options

Read-only audit of frozen runtime `b8e7e1bee6611eeda320ce163cd3ce89323da877`. DeltaBlue is the target; no benchmark edits, runtime edits, native jobs or commits. This packet prepares one grouped architecture review. A source-backed recipe census is still needed before choosing implementation scope.

## Actual route and cost evidence

Retained evidence is `build/pyjit-link-wave1/object-call-20261109/gap46-profile-decoded/record-r1-candidate-deltablue-cycles-record.report` under the `python-boil-the-ocean` checkout. Self samples: `CALL_PY_EXACT_ARGS` 11.05%, bound-method exact 1.13%, `RETURN_VALUE` 3.00%, `_PyEval_FrameClearAndPop` 1.76%, `_PyFrame_ClearExceptCode` 3.32%. Generic transaction overlap/run-vector are only 0.40%/0.88%. This is one sampled profile, not a call-frequency census or inclusive cost attribution. Inlined initialization is charged to call handlers. Do not infer application speedup by adding shares.

DeltaBlue repeatedly calls ordinary instance methods and `Strength` classmethods. It includes literal predicates/no-ops (`is_input`, `inputs_known`, `execute`, `mark_inputs`) and a simple instance-field getter (`UrnaryConstraint.output`). These are examples for general structural recipes, never a method-name whitelist. `Variable.__init__` has a default argument. Source has no `@property`; property handling matters for correctness/fallback, not demonstrated hot coverage. Generators and keyword micros are outside this first scope.

### Census calibration: changes the first-scope ranking

`build/pyjit-link-wave1/deltablue-call-model-20261110/baseline46-semantic-calls.json` records one unchanged run loop at native46: **51,422 observed Python calls**. `BinaryConstraint.output` contributes 13,717 and `input` 11,707: **25,424 calls, 49.44%**. Their immutable words are `RESUME → LOAD_ATTR → LOAD_GLOBAL → LOAD_ATTR → COMPARE_OP_JUMP → LOAD_ATTR → RETURN_VALUE → LOAD_ATTR → RETURN_VALUE`: a direction field, global/class scalar, comparison/branch, and one of two field returns. Neither is a constant or single-getter recipe.

Six constant/no-op-shaped functions account for only 463 calls (0.90%); the observed single getter `UrnaryConstraint.output` contributes 337 (0.66%). Even their combined 1.56% is only a structural candidate count, not admitted hits or cost. `Strength.stronger`/`weaker`/`weakest_of` contribute 708/1,205/804 calls, together 2,717 (5.28%); `weakest_of` contains a call and is not a pure leaf under the initial rules. The profile-based census observes semantics and changes execution; it supplies no timing, ownership cost or optimized-path coverage.

Therefore **constant/argument/single-getter recipes alone have no demonstrated large DeltaBlue opportunity**. Treat them only as an architectural stepping stone if independently useful and reusable. For target selection, compare a general bounded conditional leaf region with lean ordinary activations; do not implement a catalogue of easy low-coverage recipes first. The grouped [design overview](design-overview.md) owns the A/B selection and measurement plan.

## As-built call/return ledger

Implementation anchors: `Python/bytecodes.c` ordinary call macros; generated `CALL_PY_EXACT_ARGS`, `CALL_BOUND_METHOD_EXACT_ARGS`, `RETURN_VALUE`; `Python/ceval.c` transaction/direct binders and clear helpers; `Include/internal/pycore_interpframe.h` push/initialize/pop/publication; `pycore_frame.h` describes the cold Python frame object, not the hot activation itself.

| Phase | Owners, state and work |
| --- | --- |
| Evaluate | Caller call window owns callable, optional self and arguments. Caller LOCAL homes remain separate; consuming a window must not consume callback-current locals. |
| Resolve exact | Checked function/version pins exact immutable code; same-code functions may differ in defaults. Check PEP 523, effective argument count/self presence, stack space and recursion admission. No generic binder on this hit. |
| Resolve bound exact | Current code duplicates method self/function, replaces both window homes, then closes method wrapper before later guards. That release can run weakref callbacks. A redesign must either retain this preparation/refresh protocol or defer wrapper retirement; do not keep pre-release borrowed pointers across it. |
| Resolve defaults | `call_bind_known_python` uses cached positional layout, but guards current default shape; duplicates current default values into missing homes. Bound-method general still uses transaction preparation/fallback. |
| Reserve | Thread-owned caller uses `PushOverlapping`: arguments already occupy child homes. Only uncertain/new storage is NULL-filled by chunk initialized-watermark logic. No full argument copy or full per-call frame zeroing exists here. |
| Initialize | Move callable owner to `f_funcobj`; acquire independent code owner in `f_executable`; write base/previous/global/builtin/locals/frame-object/IR/continuation/state fields; fill constant homes, including counted mortal replacements. |
| Commit | Clear caller callable home; arguments' physical cells now belong to child. Set caller real return PC/destination, publish child current, enter recursion, reload slots/PC, conditionally skip RESUME under its existing checks. No callback is allowed while ownership is half-transferred. |
| Execute | Every frame slot is a valid owner or NULL. Caller overlap aliases are not additional owners. Code anchor is independent because function `__code__` can change during execution. |
| Return | Acquire/take the result as a canonical owner, leave recursion, unlink child and make parent current before any child-owner retirement. Result stays owned across callbacks. |
| Clear | For unescaped thread frames, scan `co_nlocalsplus`, NULL each home before release, close locals/function, then code. Successful return temporaries are already NULL: there is no release sweep over the whole temporary bank. |
| Escape | A retained `frame_obj` can take ownership of all frame homes/code/function into heap storage instead of releasing them. Profiling cache anchoring must also be updated before storage reuse. |
| Pop/publish | Restore stack top/limit or pop chunk. Honor pending caller redirect; publish/discard result, retiring any displaced destination owner only after replacement. A retirement callback can change caller PC/exec/locals; continuation refresh remains necessary. |

Properties/custom `__getattribute__` have specialized direct child creation through `PushUnchecked` and argument moves. Ordinary method lookup often already publishes split function/self, avoiding a bound-method object; classmethod lookup can still create one. Optimizing generic vector binding alone misses the dominant exact route.

## Required contracts versus implementation choices

Required: evaluated input owners; valid reusable cells; exact target/binding semantics; independent executable lifetime through callbacks; recursion/errors; complete state at callbacks/GC; supported tracing/monitoring/debugging/frame escape; real caller continuation; bounded retention. See [lifetime policy](../../design/lifetimes-and-language-semantics.md).

Choices: a full activation for a side-effect-free leaf; storing globals/builtins redundantly in each header; materializing constant slots; helper layering; scanning every local on exit; exactly when unreachable inputs are retired. Changing a choice still needs a complete replacement ledger. A mortal borrowed frame bank, dropping the executable anchor from a real mutable-function activation, or assuming all constants are immortal is unsafe. Exact CPython decref transcripts are not a language requirement, but callbacks at the selected release points require coherent state.

## Recommendation 1: certified tiny entry recipes

The structural alternative is to **remove the activation**, rather than only shrink it. Ordinary exact constant/argument returns, followed by a guarded instance-field getter, are the smallest contract examples. They can remove reservation, full initialization, code-home acquire/release, RESUME/RETURN dispatch and child cleanup, while still retiring the actual evaluated inputs. The census makes them stepping stones, not the selected high-coverage DeltaBlue optimization. It is not a full JIT and does not cover arbitrary small functions.

Certify the entire final immutable IR, after compaction/folding: the entry RESUME plus a permitted literal/constant load and RETURN, or a direct argument return with only the certified copy/borrow operations. Check def-use/return source, argument index, no other executable words/effects, no exception regions, no cells/freevars, no variadics/generator kinds, no unsupported prefix. Reject uncertainty. Do not assume a fixed word count until the final compiler forms are enumerated. Existing format roles, effect flags, immutable `co_words` and source maps make a cheap one-time classifier possible; broad effect masks alone do not prove the returned value or absence of observable entry work.

**Do not use `_PyCode_ReturnsOnlyNone` as a certificate.** It checks each return's preceding None load and allows arbitrary earlier side effects/control flow. It does not certify that the function does nothing. Classification must cover every executable word, not just the final pair, AST size or method name.

Keep recipe metadata on the code/execution object or as scalar call-site facts tied to valid function/code version. Never cache a borrowed mortal function/code/constant pointer. Version equality pins code; `__code__` replacement clears the function version, code replacement gets a new version, and version exhaustion declines specialization. At execution, derive the current code from the owned callable while still before effects. For constant recipes acquire the result from that exact code; a mortal `co_consts` replacement must be acquired as an owner or conservatively decline. For an argument result, acquire an owner before retiring the argument window. No independent code owner is needed after its final metadata read **only because no activation or later code access survives**; the real-frame path must keep its independent code anchor.

First scope: exact positional calls with every argument supplied; ordinary split self supported by the same count contract. Default values, keyword binding, bound-wrapper preparation, properties and classmethods that have not already produced a split function/self remain normal calls. This avoids importing mutable defaults into a supposedly immutable recipe. A later defaults extension must acquire the selected current default with the existing shape guard and support same-code factories with different default tuples.

### Hit and completion contract

1. Before effects: require checked function/version, standard vectorcall, exact effective arity, ordinary kind, recursion admission and conservatively retain current stack-space admission initially. Recheck recipe identity and observation eligibility. MISS preserves every input and follows the normal call. No allocation or wrapper retirement belongs in this prefix.
2. Observation guard must cover PEP 523, Python trace/profile, global/local monitoring and instrumentation generations, DTrace/LLTrace as supported, and pending eval-breaker/entry work. Merely seeing uninstrumented CALL or checking `_co_instrumentation_version > 0` is not a complete predicate. Reuse the RESUME admission semantics and explicitly audit every excluded observer. Initial conservative misses are acceptable.
3. Acquire canonical result owner while caller window/code still anchor inputs. No frame or borrowed payload escapes. Detach input owners and NULL every consumed home exactly once; the scratch record belongs in an out-of-line completion helper, consistent with current handler ABI rules.
4. Keep parent current and the real call PC/continuation valid; retire detached inputs, then refresh parent PC/exec/redirect and callback-current locals. Publish/discard the result via a shared extracted ordinary-call completion tail, preserving destination ownership and error cleanup. Exact calls must not gain the native path's periodic-at-end behavior accidentally. Do not copy `call_transaction_native` wholesale: its temporary/local publication ordering and flags differ.
5. On a post-effect refresh/error, never redispatch the original call or rebuild its inputs. Drain/park the result under the explicit error recipe. If supported observation cannot be excluded until after a release, this scope is blocked until that completion contract exists.

Retirement may change the exact moment at which finalizers see a caller result; document the chosen ordinary-call publication policy and test coherent state, not inherited finalizer transcripts. Initial scope should preserve current ordinary return's result-held-through-input-retirement order to minimize changes. Once inputs retire, a hook enabled by that callback applies to subsequent execution; it must not cause replay of the already-completed tiny call.

For the later getter recipe, certify `return argument.attr` in full IR and add a type/version/shape proof that excludes descriptors and custom accessors. Acquire the field result before receiver retirement. A missing field, descriptor, class/shape mutation or unsupported provider must miss with intact inputs, so the real callee produces its own traceback/error. A generic attribute call is not an acceptable “fast getter” because it can run Python without the skipped callee frame.

### High-coverage alternative: bounded conditional leaf IR region

Use the same whole-body certificate to admit an acyclic read-only region: argument/constant inputs, guarded instance/global/class reads, exact scalar comparisons, branch/select and return. Express its operations/effects through the shared IR semantics and generator, not a runtime loop that becomes a second Python interpreter. Bounds should follow an explicit metadata/code-generation budget, not this benchmark's nine-word bodies. Exclude calls, writes, allocation, handlers, loops and every unguarded descriptor/operator route initially; the general `EqualityConstraint.execute` call/store body remains an ordinary activation.

Immutable code certification proves the operation graph, not mutable lookup results. The direction field needs current receiver type/shape/field-presence proof; the global/class scalar needs current globals/MRO/metaclass/version proof; comparison must prove a callback-free scalar operation. A substituted object with `__eq__`, custom attribute lookup, descriptor, missing field or changed class/global must fall back before effects. Reuse the actual selected branch, or safely decline if speculative guards on the other branch fail; never perform an unchosen effect. Intermediate reads/results stay rooted by original input/global/class owners or explicit temporary owners; no borrowed mortal metadata crosses retirement.

This family could reach the 49.44% selector count, but only a measured admission census can establish hit coverage. Repeated guards can erase the saved activation work. Require complete region instruction/metadata accounting against the lean-activation option, shared observation/completion contracts, mutation/aliasing negative tests and unchanged-workload application measurement. Do not infer saved time from call frequency or add its projected gains to separate class-scalar lookup gains.

## Recommendation 2: resolved ordinary activation and cold observation

For calls that need a frame, define one resolved-target/binding view shared by exact/default/split-method entry and the existing overlapping commit. Resolve current function/code once, retain dynamic-default coverage, then commit using that selected code rather than repeatedly reselecting `func_code` across primitives. Keep original source owners intact through any allocating/preparation phase and revalidate afterward. This is a contract cleanup first; GCC may already remove some repeated loads, so source simplification alone is not a performance result.

Separate hot activation requirements from Python-frame materialization: stable base/previous/PC/exec/recipient and counted function/code anchors stay hot; redundant derived globals/builtins and observer cursors are candidates for accessors/cold side state only after an all-reader census. Keep one frame ABI and cold materialization/escape path. `frame_obj == NULL` alone does not mean “unobserved”: remote stack walkers, GC, traceback construction and hooks installed by deeper calls still need valid activation state. Do not leave garbage in fields existing readers inspect or replace them with untracked mortal views.

Pair this with a common ordinary return/retirement primitive that handles the nonescaping thread-owned case directly and takes the existing cold frame-object/gen path otherwise. A compiler-certified exit live-home/range map may later replace local NULL scanning, but only with complete handling of debugger-written locals and frame escape. The baseline already skips temporary scanning, so any range-map win must come from measured local/constant-home exposure, not an invented full-frame sweep. Keep independent code ownership through cleanup callbacks and storage geometry through chunk reuse. This redesign is broader and riskier than two exact tiny recipes; do not start by shrinking every header consumer.

## Admission and missing evidence

Root's completed semantic census calibrates the options above. A follow-up admission/owner census would need exact eligible hits, input-owner counts and method/default/observer/lookup fallback counts; observed function frequencies alone do not establish those. The first implementation requires a reviewed complete observation predicate and extracted ordinary completion contract; these are concrete unresolved interfaces, not permission to assume callbacks away.

Tests: constant/argument/mortal-constant results; argument aliasing and inline values; exact-arity errors; same-code and `__code__` replacement; custom vectorcall; recursion boundary; trace/profile/monitoring enabled before and between calls; pending interrupt/epoch changes; receiver/function/argument weakref callbacks; folded LOCAL/temporary/discard/overlapping destinations; callback redirects or local writes; retained caller frames; result survival and all homes NULL on error. For later getter coverage add descriptors, `__getattribute__`, field deletion and shape/class mutation. Retain normal-path property/classmethod/default behavior even when recipes decline.

Measure complete DeltaBlue call/setup/return/retirement instructions and elapsed time against frozen46 and controls after correctness review. Require a net application benefit with bounded memory and explicit tradeoffs; retain a useful small increment independently of later recipes. No promise of 2×, no annotation/CPI experiment, and no optimization selected by a benchmark name.
