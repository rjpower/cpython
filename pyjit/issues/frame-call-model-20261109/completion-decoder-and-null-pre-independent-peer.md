## NULL-only PRE capability

The direction in `null-only-pre-implementation-brief.md` is **accepted for a first, separately admitted source packet**, not yet approved as implementation. The current `register_resume_liveness()` uses a whole-code `null_home` exclusion: any possible writer clears the exemption everywhere. A per-PC must-NULL proof can recover the documented COPY → STORE_FAST → FOR exhaustion path. In source, COPY produces B+arg from B, SWAP exchanges B with B+arg-1, STORE_FAST expands `_SWAP_FAST` then `POP_TOP` of its A input, and `_PyEval_CompleteStep` clears FOR's B/B+1 on completion. The actual generated stores and aliases still need review when the shared query is written, including native and VM FOR routes.

The brief keeps `VALUE` and `NULL_ONLY` as independent incoming demands, requires every actual reader alias to permit NULL, and refuses a mixed demand at a join. It retains the conservative ALL-demand projection for existing strict adapters, rather than silently treating new NULL-only homes as available owners. Ordinary PRE errors forget success facts; source errors require positive completed-edge evidence. This agrees with the existing owner/provenance boundary. A source-level nullable input alone cannot turn a missing receiver or delete-value into an optional NULL. The first permission remains ordinary real-LINE PRE, with named-local binding checks and callback reproof intact. No hot path, constructor schema or general debugger-crossing permission follows from this design review.

## Shared completion specialization, separate option

`shared-completion-specialization-shape.md` is **accepted as a separate design experiment after decoder33 timing**, not as a source edit. `_PyEval_CompleteGeneratorReturn` has only two generated C callers, and both generated return cases assert the C-owned result is a canonical home before calling it. The other native/THROW callers of `_PyEval_CompleteStep` keep the generic publication entry. Literal SEND/FOR kinds and canonical input can therefore enter one shared implementation without changing the result-owner or observer contract. Forcing the whole current 1,858-byte Step body inline may clone cold observation/error/retirement code and add spills. Actual total text, hot-path calls and register pressure, plus broad timing controls, decide whether this experiment is worth retaining. The existing isolated decoder result cannot establish that conclusion.
