# Non-neutral stopped state and NULL requirements: source-grounded proposal peer

The bounded direction is approved for concrete interface design and subsequent
source review. This is not approval of an uninspected physical-transfer helper.
No runtime changes or native execution were made for this review.

The current context transfer writes shared parent tables at `PUSH_EXC_INFO` and
`LOAD_FAST_AND_CLEAR`. Excluding those operations before constructing a copied
post-edge row prevents a debugger request from changing the original analysis.
The provider declaration, actual owner site, selected edge, physical successor,
generation and committed continuation must all agree. The consumed condition's
old origin stays cut even if an output occupies the same home. A post-edge row
cannot authorize the existing pre-site survivor proof.

Two refinements are now explicit in the main proposal:

- COPY/SWAP demands propagate simultaneously to their source homes. Transport
  is not a fresh-definition kill; a required-value alias defeats a NULL-only
  alias.
- The first must-NULL analysis starts at ordinary nonsuspending fresh-frame
  entry. Generator resume, external entry and active-child overlap retain the
  strict fallback until their separate entry state is proved.

The independent expectation proof is essential: nullable CALL self accepts an
originally expected NULL, not an erased method receiver. Python binding-state
checks remain separate from ABI NULL acceptance. Ordinary error edges cannot
inherit successful definitions, and unknown partial publication must lose the
affected facts before unwind. The four actual witnesses need no error/source
precision, so conservative refusal there is sufficient for this increment.

The smallest coherent implementation has two reviewable parts: exact certified
non-neutral POST projection, then a shared cold physical-transfer contract and
VALUE/NULL_ONLY demand analysis. Neither requires new hot dispatch state or
extends SOURCE_POST, yield or suspended-frame setter authority. Actual helper,
allocation, alias and phase handling still require independent source review
and coordinator-run native gates.
