# Saved-local restoration action proposal peer

The bounded direction is approved for implementation planning, subject to the
concrete dynamic-origin conditions below and coordinator admission. This review
covers the proposal, not source or native results.

The per-local obligation vector is the correct basis. Restoring the oldest active
same-local token on a full exit recovers the binding preceding the abandoned
nested scopes; distinct local actions commute. A saved NULL is a binding state,
not missing proof and not permission to bind None. No handled-exception link or
cell mutation is admitted.

The first dynamic witness must be fail-closed: require an exact current column,
a finite same-local parent chain, an available current origin for its oldest
token, and a no-reentry survival proof from that producer to the stopped phase.
If the first implementation cannot distinguish repeated executions of a producer,
reject a reachable producer cycle rather than using static producer identity as
a dynamic generation. Require the witness for every chain member used to justify
which save is oldest/current, not only for the chosen source home. COPY duplicates
need an actual owner-preserving transport proof; equal bits or equal Python values
are insufficient. Unwind-cleared homes and lost origins must remain refusals even
when the physical cell happens to contain NULL.

Application is sound only after the entire action set and existing target/caught
root recipe pass. Allocate all arrays before mutation. Capture action sources and
displaced named-local owners, detach all surplus homes, install all restored locals,
then publish target/cursors/generation before the first close. There must be no
slot, local or PC write from the old transaction afterward. Preserve newer nested
redirects. Source homes cannot alias another action or a retained target root
without a separate move proof. Validate ordinary-local kind against actual code
metadata; name equality does not admit cells/free variables.

Warning callbacks require complete generation-aware reproof before commitment.
Restored NULL bindings must be excluded from missing-target None-binding policy;
add a target that actually observes the unbound state, so the test does not prove
only a return value or warning count. Existing behavior for unrelated unbound
locals remains unchanged.

The proposed positive/negative ladder is appropriate: prebound/unbound, independent
locals, nested same-local full exit, last-owner inspection of all installed locals,
newer redirect, lost origin, stale copied token across producer reentry and cell
refusal. Keep the corrected PRE-only tests and failed first-round evidence. Source
admission must inspect the actual cycle/transport witness and detach/install/close
sequence; this proposal review alone does not certify them.
