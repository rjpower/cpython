# Stopped-state view proposal peer

Design direction approved after reading the concrete consumer addendum in
post-restoration-capability-sketch.md. Source and native admission remain
separate. A request-owned exact-edge row, produced by the existing normal
context/save/origin transfer, avoids substituting a global landing meet for the
actual stopped state. Targets remain Analysis rows. The first inherited-context,
empty-target-scratch rung does not pretend that a pre-site FOR or caught-owner
survival slice proves a post-edge stop.

SOURCE_POST requires a positively certified provider commit, exact scoped
record/cursor/from/edge/next/generation association, and shared physical
availability checks. A newly defined value cannot restore a destroyed old saved
origin. The action builder must retain binding safety, actual token survival and
warning reproof, with owned temporary rows released on every path.

YIELD_READY represents the executing frame before suspension. Keep the outgoing
value frame-owned until the typed decision, own the callback payload separately,
and compare generation/PC after payload retirement. Cancellation must bypass all
old canonicalization, result publication and suspension/link writes. Actual
suspended frames and caught-context exits retain their separate refusal scope.
No new hot frame state or ordinary dispatch work is justified by this proposal.
