# Merged validation and performance plan

2026-11-07. GCC remains the only compiler. Keep the existing release/debug/stats
builds, flags, allocator and JIT-off policy. Startup RSS and zero-box counts
are not admission gates.

Each runtime increment gets the existing seven-kernel alternating
upstream/candidate screen after its source is committed and executable identity
refreshed. Retain the exact release ELF before the next rebuild. Report raw
candidate change and upstream-control drift separately; a smaller ELF or one
favorable noisy screen is not an elapsed-time result.

At the coherent call/contract/canonical-home boundary:

1. Regenerate from the producers, compile release/debug/stats and check the
   117-module rosters and value API. Run full release and debug suites once;
   only a material subsequent correction justifies repeating them.
2. Freeze runtime source and executable identities. Reuse the reviewed
   `checkpoint-closure/measure.py` collector for three interleaved rounds of
   all 29 kernels, five timing values per cell, upstream/interim/candidate.
   Retain the module logs, source/configuration/import probes, complete load
   tuples and retry journal. Controls stay at their existing GCC identities.
3. Reuse `measure_pyperformance.py` for the declared eight modules/twelve
   results. Include every worker and precision warning, preserving its bounded
   quiet-launch policy. No startup/RSS companion is required.
4. Reuse `diagnostic-perf.py` on deltablue, logging_silent and comprehensions
   for instructions/cycles per workload loop and selected user-cycle call
   stacks. Retain exact ELFs and running percentages. These counts have no
   matched dynamic bytecode denominator and must not be called per-bytecode
   cost. Use profiles to locate remaining work, not attribute whole-program
   elapsed differences to one sampled helper.
5. Independently recompute the elapsed geomeans and review collection identity,
   roster/load admission, warning/noise and completeness. Compare the new
   candidate/upstream gap with the preceding qualified C campaign, explicitly
   distinguishing sequential diagnostic comparisons from an isolated causal
   experiment. Preserve failed attempts; never pool their prefixes with later
   runs or select favorable rows.

the first temporary publication's numeric type tests/conversion may disappear;

repeatable speedup. If results regress or the producer proof fails, retain the
shared contract and canonical store-boundary documentation but remove the
optimization before final qualification.
