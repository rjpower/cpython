## Why this is a useful small experiment

The maintained runtime and generator paths are unchanged from `e9e10d5` at
observed primary HEAD `5163eadffafeaa82fdb8d37e9ef65bfa239e6630`.
The bound accepted image is SHA256
`289cf16e3baf69e7cbc364a9b40a46f713e6604ae1fa8e6bf94afad7857f586f`.
Its sampled normal YIELD_VALUE, RETURN_VALUE and RETURN_GENERATOR continuations
really load the resumed frame's base and store it at `-0x628(%rbp)` before
dispatch. The anchors in results.md agree with the retained disassembly.
RETURN_VALUE performs that pair after FrameClearAndPop; RETURN_GENERATOR's
remaining ordinary tag checks do not read the cache before dispatch. These are
actual baseline consumers, independent of the rejected image's additional
frame/IP spills. The CALL_PY_EXACT_ARGS and SEND_GEN prefixes establish entry
code only; their stopped branches do not prove later frame-entry costs.

`_PyFrame_Slots` returns `frame->base`. A handler-local alias removes a source
requirement to transport that derived value between handlers without changing
frame storage, instruction representation or the root model. A new dependent
load in the receiving handler may cost more, and GCC may reconstruct the old
cache. Neither a register-pressure explanation nor a speedup is established.
The proposed mechanism and elapsed checks can reject those outcomes honestly.

## Correctness conditions checked

The actual generator has 287 handlers, 19 predicted joins and five common
labels, matching the inventory. Its predicted joins follow IP publication and
instruction statistics, neither of which consumes slots. The alias must follow
the predicted label and precede feedback/window/body accesses. Placing it only
at ordinary handler entry would leave specialized misses uninitialized.

Each common label already owns a lexical scope. Its non-tail alias belongs
after TAIL_CALL_LOAD_FRAME; exception-unwind self-jumps, initial throw, unknown
opcode and inlined start-frame entry must initialize through those scopes.
The initial throw assignment in ceval.c must remain only for the tail call
once the non-tail function-wide declaration is removed. Tail parameters and
dispatch arguments retain their present convention. Switch dispatch and
transparent instruction/line redispatch must reach the same fresh binding.

All 26 existing reload assignments remain necessary source obligations until
the compiler proves an individual local store dead. In particular, unwind
writes lasti/exception through slots, and instrumented yield has distinct
error, redirected-IP and resumption routes. The alias must stay mutable after
frame switches. Window pointers, early return/yield publication, frame links,
clears, current-frame changes and exact IP publication/order remain unchanged.
The inspected generated return/yield paths publish results before unlink or
clear; reducing the alias lifetime provides no reason to alter that ordering.

The pointer is not a managed-value root. Existing precise-frame and root
checks remain mandatory, including observer, allocation-failure and collecting
paths. No new leaf annotation, root exemption or independent ownership table
is warranted. Handler-local aliases should be emitted through the shared
generator, with unused-local handling appropriate to each existing backend.

## Requirements for the next review

The prototype must prove entry placement for every actual predicted join and
common label, plus ordinary, wrapper and frame-switch routes; a total count is
insufficient. Preserve the tail/switch/debug/free-threaded source conditions.
Freeze exact native case IDs, injection modes and deadlines separately before
any execution. The design's existing frame, generator, instrumentation and
unwind controls are relevant choices, not evidence that they already passed.

For a later matched O3 image, follow actual normal and fallback continuations,
compare the three baseline exits and common controls, and report what replaces
the outgoing cache pair and receiving cache load. Report spills, dependent
loads, frame/IP residency and text size as diagnostics. Actual elapsed benefit
and control regressions decide performance under a predeclared plan; no proxy
size or instruction threshold supplies an automatic veto or rescue. The
optional unchanged-image IRA investigation is not a prerequisite to this
bounded prototype.
