# M3: one observed loop through the shared optimizer and backend

2026-11-01. Proposed source cut, not implementation or execution authority.
Source baseline: frozen M2 `3bcb891956a9d2796bbe5e92c4f0c9e2f2516899`.
The test-only successor `3174bc0ab726cb7b7b39f25d93f4ec9194c88d3a`
corrects an obsolete unsupported-operation fixture; M2 natural behavior remains
pending fresh validation. This proposal does not treat source acceptance as
runtime success.

The hypothesis is specific: an observed loop can remove repeated scalar helper
calls and intermediate home traffic while retaining the baseline's generic
calls, exact recovery and natural admission. Keep one typed CFG SSA, one LIR,
one backend and one artifact owner. Method SSA will use the same nodes later.
The complete increment requires actual recording, scalar lowering and native
execution; a graph dump or an active-code bit is insufficient.

## Recorder and publication

At the existing M2 natural compilation event, nominate at most one ordinary
interruptible loop: the lowest validated pristine backedge/header pair. No name
or workload recognition, new frame-entry test, or independent hotness counter.
Do not select `IR_JUMP`, suspension/NO_INTERRUPT loops or exceptional transfers.
Use M2's existing 64-call/256-backedge policy.

Emit a temporary recording variant of that method Unit. Only this variant has
before/outcome calls; unrelated baseline Units retain their existing bodies.
At the nominated header, begin one bounded observed iteration. Events follow
the operations actually executed; no CFG walk, operation replay or prewarming
substitutes for observation. Stop at the repeated header, invalidation, an
unhandled transfer or a resource limit. One attempt per existing JitState/source
stamp is enough for this cut; Unit retirement alone does not reset that policy.
Abort returns to the ordinary method baseline, without
repeated recording or compilation at each subsequent iteration.

Before-event data are logical frame identity/token, pristine word, source stamp,
descriptor scalar fields and input representation/scalar observations. Generate
home reads/writes, folded-local borrowing, consumption and NULL effects from
the same `IRSlotStack`/layout analysis as semantic helpers. Do not retain a raw
instruction pointer, descriptor pointer or observed object across callbacks.
An outcome supplies actual successor, scalar result observations, Action and
phase. Classify terminal Actions before reading an old frame. Allocate the
session/event capacity at the published header, then revalidate frame/source/
observer state before taking the first input observation. Per-operation event
writes never allocate, run Python or change operation inputs. Closing the record
and compiling occur at a fully published boundary with the usual cold rechecks.

An opaque C call is one ordered effect. Pause inside it, including arbitrary
callbacks, then record its actual completed result/error. A Python CALL first
records preparation and pauses. Extend the existing scalar pending token with
a recorder token; its matching normal return completes that call event after
`IR_STORE_RETURN`. Callee/callback execution does not inherit the recorder.
Exception entering the waiting caller, RETURN_GENERATOR, suspension and frame
clear retire it through the existing M2 consumers. Keep no Unit pin, code,
function, constant or argument owner across the Python callee. A linked caller
owns its language state; session data are scalars and copied source identities.

Compile an immutable replacement Unit containing ordinary baseline bodies,
the optimized loop, entry adapters and state maps. Publish only after M2's
BUILDING, source/exec/generation/epoch and observer rechecks. Detach the old
entry before release; active old bytes remain pinned and charged. The old
recording activation may leave at its committed header and reenter through the
existing natural backedge route; do not add another permanent Action engine.
If optimization fails, detach the recording variant and next publish the normal
baseline, with the attempt recorded so it cannot repeat indefinitely.

## Shared SSA and an implementable ownership boundary

Initial nodes: `HomeImport`, scalar `Constant`, `GuardExactInt32`, checked
`Add/Sub/Mul`, `And`, signed comparison, observed-path guard, `Phi`, generic
`Call`, `Publish`, owner release, poll and `FrameState`. Use an effect token for
calls, releases, polls and observable writes. FrameState and ownership uses are
liveness roots. First passes are copy/constant propagation, pure CSE and DCE;
no heap-load hoisting, inlining, escape analysis or general boxing elimination.

Actual M2 arithmetic uses generic helpers and can produce boxed `PyLong`.
Admission therefore accepts **inline int32 or exact boxed PyLong representable
as int32**, with exactness/range guards. A subclass or larger integer exits to
the original generic semantics. Importing the scalar does not consume, replace
or hide the boxed owner. The original home/alias preserves its identity until
the source operation's actual kill or overwrite.

The source distinction matters: `IR_CONSUME_INPUT` clears an owning temporary
but leaves a folded local intact; `IR_STORE_DST` installs a local's new value
before closing its displaced owner. Initially optimize borrowed-local reads and
inline intermediate temporaries. Preserve the whole generic operation when it
would consume a boxed owning temporary whose intra-word release/publication
sequence is not represented, notably a boxed call result. This is an ownership
boundary, not an inline-only entry restriction or a per-program whitelist.
M2's boxed loop locals can enter; pure chains on them can become native.

For a local overwrite, reconstruct its new inline value and publish all state
visible at the exact source commit, then close the displaced home owner through
the existing release semantics. That release is a statepoint: even exact PyLong
destruction can reach replaceable allocator hooks. Never defer it past a later
call or incorrectly label it infallible. Preserve NULL homes, aliases and
source read-before-write order. A callback sees the same committed home state;
afterward validate the live frame/owner and reimport facts it could have changed.
Use existing inline `PyStackRef_FromInt32` recovery on the supported default
representation; boxed-policy execution stays baseline until it has a valid
materialization plan. Imported boxed identities are not rematerialized numbers.

Concrete first program shape:

```python
def work(n, positive, py, obj):
    i = total = 0
    while i < n:
        u = i * 3
        v = u + (i + 7)
        total = total + v if positive else total - v
        a = py(i)
        b = abs(obj)
        total = total + a + b
        i = i + 1
    return total
```

Vary all inputs; `obj.__abs__` can return changing values, raise or invalidate
observers. `positive` exercises both paths across invocations; a second fixture
changes a branch within the loop and checks a real side exit. The first integer
chain and induction update are the optimization target. The boxed call-result
operations may remain helpers. Current source evidence is the actual compact
integer guards/operations in `bytecodes.c:662–740` and ownership macros in
`ceval_macros.h:625–664`; this sketch is **not a claim of captured word offsets**.
The diagnostic producer must capture real words, folded roles, NULL/owner maps
and the executed events for this program before claiming successful lowering.

Loop-carried home versions become PHIs with import and observed-backedge inputs.
Checked overflow exits BEFORE the arithmetic; a path guard exits before the
unexecuted branch arm. Completed call/store/release exits resume AFTER. Errors
preserve the pending exception and original raising word, without replaying any
effect. Reserve recovery storage before effects; publishing an AFTER state must
not allocate. A guard side exit materializes and transfers to this Unit's normal
baseline body at the exact word; it does not call the unsupported-op path that
permanently disables the code.

## Real LIR, allocation and continuation maps

M2 has only HELPER/BRANCH/EXIT, `nops == source words`, and word-indexed offsets.
Remove that equivalence explicitly. Separate source WordId, SSA ValueId/NodeId,
lowered OpId, NativeLabel and recoverable EntryId. Preserve a word→baseline
entry map; add guarded canonical import entries at the loop header and each
post-call continuation. Internal PHI/backedge labels are not callable entries.
All external resume routes enter the existing SysV prologue before selecting an
ENDBR-protected adapter.

Extend the common LIR with scalar imports/moves, checked int32 operations,
comparisons/guards, parallel PHI copies, spills, publication, statepoint calls
and native edges. Implement actual loop-aware linear scan with snapshot uses,
backedge live intervals and call-clobber splitting. Use six caller-saved integer
registers `RAX/RCX/RDX/R8/R9/R10`, `R11` for parallel-copy/fixup scratch and
existing `R12` for context; reserve ABI argument registers at calls. Resolve PHI
cycles via scratch or a bounded spill. Spill live caller-saved scalars across C,
maintain 16-byte call alignment and distinguish raw scalar spills from owners.

A C call publishes canonical live owners before reentry. After success, import
its actual result and kill mutable heap and frame-alias facts; allocator hooks
or `f_locals` access can change homes. Preserve the active Unit pin until machine
return. A Python call publishes all live state, ends that activation and uses
M2 pending flow. Its return resolves the currently published Unit and imports
**all** live continuation values/guards anew. Never carry earlier registers,
facts or a raw native label across that transfer.

Preserve every real periodic check. On the current Linux/x86-64 GIL target,
the Emscripten and QSBR macros in `check_periodics` are empty; its event-bit
test can be lowered as a native fast poll, with epoch mismatch also taking the
slow path. Slow path publishes state and invokes the existing generated
JUMP_BACKWARD service exactly once before resuming its committed target.
Other configurations retain the helper. Prove this compile-configuration
equivalence rather than assuming all safepoint work is a bit test. Successful
native backedges retain PHI registers; polls/calls release them only when needed.

## Source cut, bounds and evidence

| Boundary | Actual files to extend / proposed new files |
|---|---|
| Event/effect metadata and hooks | `Tools/cases_generator/{ir_generator,jit_helpers_generator}.py`, `Python/generated_jit_helpers.c.h`; use existing DSL/layout analysis |
| Recorder and shared graph | new `Python/jit_record.c`, `Python/jit_ir.c`, `Include/internal/pycore_jit_ir.h`; common graph, not private trace bytecode |
| Scalar LIR/allocator/backend | `Include/internal/pycore_jit.h`, `Python/{jit_baseline,jit_backend_x86}.c`, new `Python/jit_regalloc.c`; bounded additions to `jit_x86.h` only where required |
| Session/continuation/owner | `Python/{jit_runtime,ceval,instrumentation}.c`, existing transfer macros and pending consumers; restore/detach before free |
| Integration and checks | `Makefile.pre.in`, existing `Modules/_testinternalcapi.c`, `Lib/test/{test_jit_method,test_generated_cases}.py`; no new selector |

Initial mechanism bounds: one recording session per existing Flow, one nominated
loop/path per State/source stamp, 512 events, 1024 values, 2048 nodes, 256 states,
4096 map entries, 64 recoverable homes and 64 eight-byte spill slots. These are
compile limits, not claims of optimal thresholds. Charge session/graph/maps and
retired artifacts to M2's 8MiB budget, retaining the 64-Unit cap and optional
resource cooldown. No separate unbounded compiler-memory domain. Quota/OOM
abandons optimization; real hook-set errors propagate at their actual phase.

Implement in three bounded commits, retaining one final execution path:

1. Real paired recorder and generated home/effect contracts, with terminal and
   Python-return event pairing; preserve ordinary baseline bytes elsewhere.
2. Shared SSA verifier/passes, maps, scalar LIR and allocator; actual encoder
   fixtures prove signed overflow exits, PHI cycles, more than six live values,
   call spills, relocation bounds and allocation failure. No C arithmetic mirror.
3. Replacement publication, native trace entries/side exits and mixed-loop
   fixtures. A partial earlier commit is not M3 completion.

Cheap host/generator and source checks precede a bounded compiler check. Fresh
focused behavior then covers nonconstant/zero/repeated iterations, changing
branches, exact boxed/inline/subclass/large values, overflow, owner finalizers,
Python/C calls, errors and callback invalidation. Force exits and compare actual
result/effect/traceback/owner state. Inspect complete emitted bytes, stack/RX
lifetime, register chains, spills and native backedge; prove a fresh Python-call
return enters its trace continuation with imports, not merely baseline entry.

Diagnostic runs expose bounded before/outcome records, native trace/continuation
witnesses and debug-only exit/helper counts outside timing. Later measure cold
record/compile cost and warm mixed-loop elapsed against M2 and matched RC, then
the fixed M2 six-workload matrix. Do not add a per-operation all29 vote or infer
release frequencies from seen bits. A loss selects the next pass or admission
policy; the method/tracing architecture remains the chosen direction.

This follows the already-reviewed separation illustrated by
[LuaJIT recording](https://github.com/LuaJIT/LuaJIT/blob/v2.1/src/lj_record.c),
[snapshots](https://github.com/LuaJIT/LuaJIT/blob/v2.1/src/lj_snap.c) and
[Maglev SSA/recovery](https://v8.dev/blog/maglev). Their ownership models are not
Python's. No new external survey or implementation was performed for this cut.
