# Remaining qualification after restart

The original [90-minute attempt](plan.md) expired incomplete. Preserve every
completed result and failure envelope. This is a separately bounded batch of
the remaining checks on the same frozen union, not a retry of the full ladder.

## Hypothesis and scope

Unchanged frozen source, products, configurations, tools and borrowed headers
allow the completed checks to stand after a machine restart. Finish the missing
checks without rebuilding or repeating release full or backend controls.
Coordinator owns execution and integration; an independent reviewer checks the
restart bridge and final landing evidence.

Before native launch, validate all original loader bindings, source cleanliness,
retained artifact hashes, actual idle executable state and lock availability.
Complete the missing release-full post-cleanup receipt only after that current
observation. Record the new boot ID and the retained source/product identities
in `build/restart-recovery/qualification-preflight.json`.

Use the unchanged literal launches and helpers recorded in frozen
`build/nursery-shape-broad/launches.json` in the qualification worktree. Run,
serially, debug full OFF/N0, debug full KILL/N0, release stress11 OFF/N1000,
debug stress11 OFF/N1000, ASan16 KILL/N0, and closure. Complete each row's existing
post-cleanup verifier before the next. Retain the original filters, protected
IDs, skips, worker/auxiliary/origin witnesses, root counters and limits. Closure
requires all six broad result/cleanup receipts including the carried release.

## Budget and decision

Budget **60 minutes from the first remaining native launch**, including review.
Record the start/deadline before launch. Checkpoint after debug full OFF, after
both full debug modes, and after stress/ASan before closure. Clamp each command's
existing outer timeout to the remaining batch time. Existing build locks,
global admission slots and suite serialization still apply.

Stop at the first unexpected source/product/environment/worker/skip/root/test
failure or deadline. Preserve its terminal envelope and perform owned cleanup.
Reserve terminal-verification time before each launch. Safety cleanup may
finish after expiry, but earns no qualification acceptance after the deadline.
Diagnose before proposing a separately scoped correction; no automatic retry.
Accept the coherent union only after every required carried/refreshed scope and
independent landing review passes. Then integrate with an explicit prose-only
source bridge and one release/debug post-merge smoke under the validation
contract. Nursery stays opt-in and no speedup is inferred from qualification.
