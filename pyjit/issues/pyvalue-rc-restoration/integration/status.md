# Integration and baseline handoff

The coordinator owns live application, index projection, commits, shared builds
and merged validation. See the [integration workstream](../../../stages/01-runtime/workstreams/integration.md)
for the loop and [HANDOFF](../../../HANDOFF.md) for exact current execution state.

Dependent reviewed source may be checkpointed with its unbuildable status
explicit. A component pass or commit is not runtime admission. Close concrete
compile/link and ownership gaps under reviewed rules, then run startup and
focused value/lifetime tests on the actual linked candidate.

[Stage 2](../../../stages/02-baseline/README.md) owns broader qualification and
matched JIT-off timing. Preserve the unchanged 29-workload roster, raw vectors,
toolchain/build identities and selected profile. Separate startup, lowering and
warm execution; compare upstream, interim RC and the unified interpreter.

Current build counts are maintained in [STATUS](../../../STATUS.md) and raw evidence
in the [merged build record](../merged-build/status.md). No restored timing exists.
Historical component details remain in their records and Git; use actual failed
builds, not stale dated assignments, to choose the next port.
