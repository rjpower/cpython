Disposition: **agree with deferral and rejection of the allocated descriptor
framework**. The fixed two-word rival is a coherent proposal for later review,
not implementation or performance GO. Common-constant producer transport takes
priority.

The revised proposal addresses the material initial objections. It charges the
next-word load, handler comparison and operand decode rather than claiming to
remove all second-site decoding. It adds no exec/frame pointer, allocation,
reverse index or generation framework. It explicitly acknowledges that encoded
images have no existing cross-word SSA/last-use API. Its finite INT geometry
reaches the retained `A4/B4/C5 → A3/B3/C4` consumer without unproved vacancy or
local old-owner claims. Compiler IDs cannot bypass common constructed-image
checks. FLOAT is correctly a separate admission: the retained consumer includes
a folded local input and local final destination.

No new semantic contradiction was found in the specified exits. First failure
executes the first ordinary site on unchanged homes; second failure commits the
entire first poststate and enters the second site once. On success homes 4/5
must still be physically NULL and home 3 owns the product. Guarded inline inputs
do not carry hidden heap owners. Both integer overflow points, operand scaling,
mixed-float acceptance, NaN boxing and separate rounding remain explicit.

Before any future implementation GO, close these concrete obligations:

- Compose actual per-site source graphs by substituting encoded fields with
  physical homes and producer/consumer token identities. A concatenated action
  list is insufficient when fields alias. Prefix and final commits must come
  from the same reached ordinary store/retirement receipts. An opaque scalar
  primitive or a declaration without its reached receipt must reject admission.
- Provide the bounded encoded read/kill/no-interior-entry algorithm, including
  EH/recovery rejection. `owner_handler_safe` is a private completion proof,
  not an existing generic value-liveness service. No absent/NO_HOME fact may
  become incoming NULL, readability or an owner.
- Show that instrumentation enabled **after installation** cannot execute a
  stale learned head and skip site 2's event while that word remains unchanged.
  Refusing installation under observation is not sufficient by itself. Either
  existing instrumentation removes the head before enabling returns, or a
  necessary entry guard must be explicit and charged. Preserve ordinary wrapper
  saving/restoration, redirects and interior entry. If this needs a new global
  invalidation system, keep the trial deferred.
- Price the emitted native path before expansion. One next-word guard/decode,
  external loads and branches can consume the saving from one removed dispatch
  and intermediate store/load/tag check. A reusable source kernel must not
  materially worsen ordinary arithmetic handlers. FLOAT additionally requires
  the contraction barrier and separately rounded native operations with unchanged
  flags; local retirement must finish materialization before callback/GC.

The proposed tests cover these boundaries, aliases, malformed public images and
all slow exits. No universal scalar-home or observer authority follows from
this peer. Only source reading was performed; no runtime, generator, build,
benchmark or tool was changed or executed.
